# DeepSeek V4.1 Flash デモ集

無料のDeepSeek V4.1 FlashがOpenCode V2で書いた、ブラウザで動くデモ8作品です。各作品は単一のHTMLファイルで、外部依存はありません。データはすべて架空で、機密情報は含みません。

- `tetris/` テトリス風ゲーム（ホールド、NEXT、ゴースト、効果音、ハイスコア保存、タッチ操作）
- `3d_model/` 3Dお城ビューア（素のWebGL）
- `bench_physics/` 物理サンドボックス（ボール1500個）
- `bench_interpreter/` 自作言語のインタプリタ（内蔵テスト付き）
- `bench_maze/` 迷路の生成と経路探索の可視化
- `block_blast/` ブロックブラスト風パズル（8x8盤面、ドラッグ配置、コンボ、ハイスコア保存、タッチ操作）
- `block_blast_deluxe/` ブロックブラスト・豪華版（canvas演出、コンボ5段階、全消し花火、BGM・効果音つき）
- `minecraft_like/` マイクラ風ブロック世界（素のWebGL、手続き生成地形、チャンクメッシュ、昼夜サイクル、破壊と設置）
- `compare/` DeepSeek V4.1 Flash Free と GLM-5.3-Flash Free の同一課題比較（7課題、プロンプト・設定・生成物・採点結果つき）

- `grassland/` 草原の風景（DeepSeek V4.1 FlashがBlender 4.2のスクリプトを生成。風で揺れる草、流れる雲、カメラ前進、8秒のmp4とglb付き）

公開ページ: https://8bitgrokbot.github.io/deepseek-demo/
