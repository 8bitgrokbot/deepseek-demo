  Mini 言語の仕様（クリックで展開）
  

    データ型: 数値 / 文字列 / 真偽値 / nil / リスト / 関数。偽とみなされるのは false と nil のみ。

    宣言: let x = 10　関数: fn add(a,b){ return a+b }（無名関数も可）

    制御: if/else if/else, while cond { }, for x in list { }, break, continue, return

    演算子の優先順位（低→高）: or < and < not < == != < < <= > >= < + - < * / % < **（右結合）< 単項 -

    組み込み: print, len, push, range, str, num, map, filter, reduce, sort, join

    安全装置: 実行ステップ上限、再帰スタック深さ上限、行・列付きエラー。
