現在のディレクトリにある index.html は、スマホ向けのブロックパズルゲーム（8x8盤面に3つのピースを置いてラインを消す）です。これに「やり直し（Undo）」機能を追加してください。index.html を直接編集し、他のファイルは作らないでください。

仕様:
1. 画面に <button id="undoBtn" type="button"> を追加する。ゲーム中に常に見える位置（HUDまたはピースの近く）に置き、スマホ縦画面（幅390px前後）でレイアウトが崩れたり横スクロールが出たりしないこと。ボタン内に残り回数を表示する <span id="undoCount"> を含める（例: 「↩ 戻す (<span id="undoCount">3</span>)」）。
2. 直前に行ったピース設置を1手だけ取り消す。取り消すと、盤面、スコア、コンボ、トレイのピース（取り消した設置で使ったピースが元の位置に戻る）が、設置する直前の状態に完全に戻る。ラインが消えた設置を取り消した場合は、消えたラインも元に戻る。
3. やり直せる回数は1ゲームにつき3回まで。回数が0、または取り消せる設置が無い（ゲーム開始直後や、直前に取り消した直後）の間は、ボタンを disabled にして見た目でも押せないと分かるようにする。連続で2手以上さかのぼる必要は無い（直前の1手のみ）。
4. リスタート、リトライ、新しいゲームの開始時には回数を3に戻し、ボタンは disabled にする。ゲームオーバーになった後は取り消せなくてよい。
5. 既存の機能（ドラッグ設置、ライン消し、コンボ、ハイスコア、ポーズ、ミュート、演出、既存の window.__game API の全メソッド/プロパティ）を壊さないこと。
6. window.__game に、取り消しを実行するメソッド undo()（成功したら true、できなければ false を返す）と、残り回数を返すプロパティ undoLeft（数値）を追加する。ボタンを押した時と undo() を呼んだ時の動作は同じにする。

完成したら、変更内容を短く日本語で説明してください。
